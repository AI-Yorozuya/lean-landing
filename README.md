# lean-landing — 一頁式官網種子

跟 AI 對話，做出一頁屬於你的官網，**免費掛上網路、拿到真網址**。

**不用會寫程式。** 你只要回答問題、看畫面、點頭——其他都是它做。

## 你會做出什麼

一頁到底：招牌 → 你在做什麼 → 三個亮點 → 關於 → 聯絡鈕。

聯絡鈕接你**現在就在用的** LINE、電話或表單——客人按一下就找到你，不用改習慣。

換行業、換顏色氣質、改文案，都是跟它說一句話的事，改完馬上在畫面上看到。

## 開始

**1. 裝 [Claude Code](https://claude.com/claude-code)** —— 照它網站上的指示裝，這是唯一要你自己裝的東西。

**2. 打開它，把這句話貼給它：**

> 我要做一頁式官網，種子在這裡：https://github.com/AI-Yorozuya/lean-landing

就這樣。它會把種子抓下來、開始問你問題，一步一步帶你走。

## 接下來都是對話

它會問你幾個問題（你做哪一行、想要什麼氣質、客人怎麼找你），每答一題，你的頁面就變一次。

你只要用平常講話的方式跟它說，例如：

- 「顏色再溫暖一點」
- 「標語改成『十年手工麵包』」
- 「這張照片放上去」（把圖直接拖給它）
- 「**上線**」—— 它會帶你免費部署，拿到一個真網址
- 「幫我**備份**」—— 把原稿存到雲端，換電腦也找得回來

過程中如果電腦少了什麼工具，它會自己發現、自己裝，你按個同意就好。

## 關掉之後想再改

隨時回來：在 `lean-landing` 資料夾裡打開 Claude Code，說一聲「繼續」。它記得你上次做到哪、選了什麼。

開場若被問「要不要載入這個資料夾的設定」，按允許——那是它在幫你把劇本換成最新版（只更新它自己的劇本，你的網站和進度一個字都不會動）。

## 這頁做不到的事

這是一張**門面**，不是一套系統——沒有後台，它不會替你收名單、記客人、排預約。

好處是：免費上線、幾乎不用維護、不會壞。

哪天你想要「自己收名單、管客人、接單、讓客人線上預約」，跟它說一聲，它會帶你往下走一步——**官網原封不動繼續掛在網路上**，你的招牌和氣質一起帶過去。

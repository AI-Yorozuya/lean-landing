# 亮相SOP・上線與上線後支線（Workers Static Assets）

> 學員說要上線時 Read 本檔照跑——這是容易出錯的實際操作，**步驟與順序照做**；跟學員怎麼說照 SKILL.md 的說話方式自然生成，示例僅供參考。含：部署⓪–⑥、GitHub 備份、自訂網域（選修）、通關。



> 實測基準（2026-08-28，wrangler 4.127，全程 27 秒）：上傳 19 檔 3 秒 → 部署 10 秒 → 生效 5 秒；**網址第一次 curl 就 200，沒有空窗**；wrangler 印出的就是最終網址。**照順序跑、別自己簡化**：

**⓪ 預覽狀態確認（不重開）。** 學員剛完成本機驗收、預覽還開著 → **不再開一次**，直接進①；預覽已關或隔次回訪才補開 `site/index.html` 讓他看著這一版上網路。

**① 部署工具進場（整條流程唯一需要 Node 的時刻）。**
- 先預告（示例）：「上線要用一個部署工具，我先確認你電腦有它需要的東西——第一次裝可能要幾分鐘，畫面會跑英文訊息，是正常的。」
- **一次判斷、一次裝對**：先看 `node --version` 與有沒有 brew——版本 ≥ 22 直接過；低於 22 → mac 直接 `brew install node@22 && brew link node@22 --force --overwrite`（**先白話說明**：這會把電腦預設的 Node 切到 22 版；沒 brew 用官方安裝器）／Win `winget install OpenJS.NodeJS.LTS`。**不要先裝一輪再改判斷。**
- 裝完**開新終端機**再驗一次 → `npm install`（只裝鎖版 wrangler，約半分鐘）。

**② 檢查 CF 帳號**（沒有→「幫你的網站辦個門牌處」當場辦，是價值兌現不是門檻）
- **能同框就同框**：環境有內建瀏覽器面板（開窗用的那個）→ 把 `dash.cloudflare.com/sign-up` 直接開在裡面，學員不用跳出去。教練只導頁，**表單一律學員自己填**。內建開不順（跳機器人驗證、載不動）→ 退回系統瀏覽器，不糾結。
- 講清楚交接方式：「註冊好回來跟我說一聲就行——**帳號密碼不用給我、也不用打在對話裡**，等下跳出授權頁，你按一下就好。」帳密永遠不進對話。
- ⚠ **註冊完要確認他「已經在瀏覽器裡登入」才進下一步**（實測 2026-08-28 踩到）：授權流程**沒有帳號選單**，它直接authorize瀏覽器當下登入的那個 Cloudflare 帳號。他如果剛註冊完沒登入、或瀏覽器還登著別的帳號，授權出來的會是錯的帳號，而且不會有任何警告。
  → 一句話帶過：「先確認你現在瀏覽器裡登入的是剛辦的那個帳號——等下授權會直接用它，不會再問你要哪個。」

**③ 授權：`npx wrangler login`**
- **開跑前先講這句**（授權頁會列一長串權限，學員在這裡最容易退縮）：
  「等一下瀏覽器會跳出 Cloudflare 的授權頁，上面**會列一長串權限**——那是這個工具的通用清單，不是我們要用的。我們只會用到其中一項：把你的網站檔案放上去。看到就按綠色的 **Allow**。」
- 這個指令會**卡住等他授權**：背景跑，別讓自己 timeout。
- **授權頁一定要開在「登入著正確帳號的那個瀏覽器」**：剛剛註冊若是在內建瀏覽器做的，就把授權網址貼進**同一個內建瀏覽器**開（localhost 回呼同機都通）——別讓 wrangler 自動開系統瀏覽器，那邊的 session 可能是別的帳號或根本沒登入。
- **要換帳號時**：`npx wrangler logout` 只清掉本機憑證，**不會影響瀏覽器的登入狀態**——所以還要在瀏覽器登出 Cloudflare，或用無痕視窗開授權網址，否則又會授權到同一個舊帳號。
- **想自己控制在哪開**：`npx wrangler login --browser false` 會只印網址不自動開瀏覽器（管線會擋住輸出，別接 `| tail`）。
- **授權完自己驗一次**：`npx wrangler whoami` 確認 email 與 Account 是他要的那個，再往下部署。授權錯帳號而不驗，會一路部署到別人的帳號上。

**④ 先問網址名——絕不代取。** 網址是他要傳給客人的東西，取名權是他的。
「上線前先決定你的網址名。我建議用 `{招牌名的英文或拼音}`——這樣可以嗎？想換直接說。」
- 只吃**小寫英數與連字號**：中文招牌一定要轉拼音／英文，給他挑、他點頭才算數。
- 選定 → 教練把 `wrangler.toml` 的 `name` 改成這個名字（這是他的 repo，名字就該是他的）。

**⑤ 部署**

```
npx wrangler deploy
```
（讀 `wrangler.toml`：`name`＝學員取的名、`[assets] directory = "site"`——上傳的就是他一路看著的那個資料夾，**沒有 build、沒有轉換**。）
- **回讀輸出裡的網址**：首次部署 Cloudflare 會拿 email 帳號名自動生成「帳號代號」（不會問；教練代跑是非互動模式，wrangler 的詢問不會出現）——所以這個第一版網址是**臨時的、含學員信箱帳號**，**絕不外流、絕不唸給任何人**。
- 教練 curl 確認 200（部署本身成立）即可，先不揭曉。

**⑥ 帳號代號——學員親手改，改完才算亮相**

- 網址兩層：`{網址名}.{帳號代號}.workers.dev`；帳號代號全帳號共用，之後每個作品都掛它下面。
- **⚠ 憑證紀律（P0 拍板 2026-08-28）：不讀、不印、不解析 wrangler 的 `oauth_token`；只用官方 wrangler 指令與官方後台頁面。**（曾試過用 token 打 API 直設代號——已否決；帳號設定本來就該學員親手。）
- 帶學員自己改（教練只導頁）：開 `dash.cloudflare.com` → **Workers & Pages** → 右側 **Your subdomain → Change** → 填招牌拼音（同網址名命名規則，他點頭才算數）。先講清楚：「這段會出現在你每個網站的網址裡，現在不改就是你的信箱帳號。」
- 這個區塊在帳號還沒有任何 worker 前**不會顯示**（實測）——所以這一步必然排在部署後，不是我們偷懶。
- 改完教練驗新網址：`dig +short {網址} @1.1.1.1` 拿 IP → `curl --resolve` 到 200（**本機 DNS 快取會把舊網址的否定結果記住而誤報失敗**——別誤判，快取毒不到學員那邊）→ 學員親眼打開 → 才算完成。
- **鐵律：代號確認之前，網址一個字都不准發出去。**
- 帳號已有代號（回訪／第二個作品）：跳過改代號，部署完直接揭曉。
- 揭曉後補一拍（本課核心教學句的實體）：「看個彩蛋——在網頁上按右鍵『檢視原始碼』：**跟你電腦裡那份是同一個檔案**。網站放上雲端，程式還是在看的人的瀏覽器裡跑。」

## 備份（上線後輕提一次，選配不糾纏）
「網站的原稿都住在你這台電腦裡。想多一層保險（電腦壞了、換電腦都找得回來），我幫你**備份上雲端**：辦一個免費 GitHub 帳號就行，兩分鐘。現在辦，或以後說『備份』都可以。」
→ 願意＝辦個家三步（教練代跑，學員只按授權）：
  ① `gh auth login`（瀏覽器授權；沒裝 gh → mac `brew install gh`／Win `winget install GitHub.cli`）
  ② `gh repo create {招牌名拼音或英文} --private --source=. --push`
  ③ 「備份好了——以後每次存檔我都會順手同步上去。」PROGRESS 記備份（repo 網址）。
→ 不要 → 「好，隨時說『備份』就辦。」不再提。
時機紀律：**只在亮相後**；絕不在裝修中插註冊、絕不與 CF 註冊疊同一拍。

## 自訂網域（選修，需求觸發，絕不主動推）

> ⚠ 待實測：CF 後台買網域的實際選單路徑、買完是否自動建好 zone、憑證要等多久——第一次真的帶人走完，把實際畫面補回本節。

**只在他自己開口才跑**：「這網址好醜／不夠正式／我要印名片／可以用我自己的網址嗎」。他沒問就當這一拍不存在——免費層的招牌是「免費上線」，主動兜售年費會把招牌砸了。

**他說「我買好網域了，帶我接上去」** → 錢已花、意願已定：跳過確認與購買（下面 1–2），直接第 3 步接線＋第 4 步驗收，別再重問一次要不要辦。

先確認他真的要（待決合法，不慫恿）：
> 「先講清楚：`{現在的網址}` 一樣能收客人、Google 一樣找得到，不換完全沒問題。換自己的網址是為了名片和招牌上好看——**這要年費——幾百塊台幣一年，實際價格結帳頁會直接顯示，付給 Cloudflare 不是付給我們**。要辦嗎？」

要辦 → 走 `.com`（**買在 Cloudflare，跟網站同一家**，不用再辦帳號、不用碰 DNS）：
1. 先問名字，只吃小寫英數與連字號；中文招牌轉拼音或英文，**他點頭才算數**（同上面④，取名權是他的）。
2. 帶他到 CF 後台 → **Domain Registration** → 搜名字。**這一拍教練代跑不了**（在他的瀏覽器裡、而且要刷卡）——講明白「這幾步我只能在旁邊帶，付款你自己來，我不碰你的卡」。
3. 買完 → **教練代跑接上去**：`wrangler.toml` 加兩行再重新 deploy（官方 wrangler 設定法；`仍需實測`——第一次真接時驗，不行就退後台路徑）：
   ```toml
   [[routes]]
   pattern = "{他的網域}"
   custom_domain = true
   ```
   後台備援路徑：Workers & Pages → 他的專案 → Settings → Domains & Routes → Custom domain。
4. **驗收照上面⑥的紀律**：自己 curl 到 200 再喊他打開，別讓他第一眼看到憑證還沒發好的錯誤頁。
5. PROGRESS 記「自訂網域：{網址}」。原本的 `*.workers.dev` 不關、兩個同時通——講一句讓他安心。

**他說「我已經有網域了」（掛在 GoDaddy／Gandi 等別家）** → ⚠ 高警戒支線，預設不推：Workers 硬性要求 nameserver 搬進 CF，而**搬 nameserver 會把他整個網域的 DNS 一起搬過來**——上面若跑著公司 email（MX 記錄），沒接好＝email 斷掉，這對小店是真傷害。要走就先盤點他網域現有的記錄（尤其 MX），CF 匯入後逐筆核對，確認 email 還通才切。不確定就勸他：官網用新買的 `.com`，舊網域不動。

**他堅持要 `.tw`** → 不勸退也不慫恿，把代價講白讓他選：
- **Cloudflare 不賣 `.tw`**（Registrar 的 ccTLD 只支援 .ca/.co.uk/.nz/.mx/.co 那幾個），得去 TWNIC 認證的註冊商買（Gandi 等），比 `.com` 貴一截（實際牌價以註冊商當下顯示為準）。
- 而且會多兩拍：CF 後台 **Add a site** 把網域建成 zone → 回註冊商**把 nameserver 換成 CF 給的兩組** → 等生效（可能要幾小時）→ 才回 Workers 加 Custom domain。**Workers 的自訂網域硬性要求 nameserver 在 Cloudflare**（外部 DNS 掛 CNAME 這條路不存在），繞不過。
- 講法：「`.tw` 台灣味比較夠，但要多辦一個註冊商的帳號、多刷一次卡、中間還要等生效。你要的是名片好看的話，`.com` 今天就能好；一定要 `.tw` 我也帶你走，只是慢一點。」

## Boss「亮相」（通關）

通關＝拿到 `*.workers.dev` 真網址、當場打開。
收尾（示例）：「這頁現在活在網路上了。傳給一個人看看——**等第一則不是你自己填的詢問進來**，你就正式開張了。」（第一則真詢問＝開張徽章，記進 PROGRESS，不設閘。）

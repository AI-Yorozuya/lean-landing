# 劇本・一頁式品牌官網（speedrun v2）

> 教練照本檔演。目標：**最少對話 → 一版真的能收詢問的一頁網站 → 免費上線**。
> 起手種子＝**本 repo main**（clone 即演，無分支切換）。純前端、零 Docker、只跑 vite。
> **五站對映（設計註，不對玩家講）**：這條 speedrun＝五站的極速壓縮形——先開窗＝**原型先行（刻意例外）**：意圖站不前置訪談，由序幕事實題＋Q1/Q4 後置補收；存檔幕產意圖草稿（INTENT.md）與知識架構圖 T0（架構圖.md）＝意圖站＋架構站補票；成品站＝亮相。

## 誠實 MVP（不做假頁；也不過度工程）

一頁公開網站，**訪客看完真的找得到他**：Hero → 亮點卡 ×3 → 關於 → CTA（打電話／加 LINE／mailto／嵌現有表單）。無 DB、無後端 → 免費上線、近零維護。
「要在後台管名單／接單／收預約」＝**全端＝畢業訊號**：記升級意向、首次仍純前端走完，回訪走 `graduate`。本 repo 永不加後端。

## 問法內核（asking 的店外複本——改 jarvis `asking` 要同步這裡）

1. 一次只問一題；答案會翻轉下一步的先問。
2. 事實自查：平台、git、node、CF 帳號自己偵測，不拿去問玩家。
3. 每題給可點選項＋預設建議；玩家答不出→**不猜、不催**，用「先照 X 做，之後隨時改」接住（待決合法）。
4. 問具體事件不問統計（「最近三個客人怎麼來的」問得出、「客源比例」問不出）。
5. 文案要他點頭才算數；教練代擬的一律講明「先幫你放了，想改隨時說」。

## 演出腳本（先開窗，再裝修）

> **魔法時刻不許押後**：取完名 90 秒內讓他看到自己的店；之後每答一題、頁面當場變一次。
> 他不是在填問卷，是在看自己的店被裝修。

**序幕・接單**（第一則回覆）
「好，這單我接了。兩件事就開工——
①幫你的官網取個名字（想好再改也行）；
②順口問一句：**最近三個客人，是怎麼找到你的？**」
→ 取名＝所有權儀式，此後全程叫招牌名。
→ 事實題答案（LINE 傳的／朋友介紹／IG 看到…）教練收成**一句意圖草稿**，開窗前回述一次：
「所以這頁的任務是：**讓{被介紹來的人／搜到你的人}一眼確認你是誰、看完就能{加 LINE／打給你}**。開工。」
（背景：clone 未完成先完成；第一次動手前講權限安心話術。答不出事實題→不追問，先照通用做。）

**第一幕・掛招牌**（取名後立刻，目標 90 秒內開窗）
動作：改 `src/App.vue` 的 `site.brand`＋`index.html` 的 `<title>` → 裝依賴（「我把工具搬進來，約半分鐘」）→ 起 vite → **幫他開窗**：環境有內建瀏覽器／預覽面板就開在裡面（同框裝修最魔法）；沒有才開外部瀏覽器。
台詞：「**開窗了——招牌已經掛上去。**接下來邊聊邊裝修：你答一題，頁面就變一次。」
防呆（雙平台 day-1）：
- 先偵測平台與工具（`git --version`／`node --version`）。
- **mac**：缺 git → 系統跳 Command Line Tools 安裝框，預告他按安裝；缺 Node → `brew install node`（沒 brew 用官方安裝器）。
- **Windows**：缺 git → `winget install Git.Git`；缺 Node → `winget install OpenJS.NodeJS.LTS`；裝完**開新終端機**才吃得到 PATH（主動講）；指令用 PowerShell 語法（`start` 不是 `open`；路徑反斜線；不用 `&&`）。
- 工具裝完一句「工具就位，繼續」。不讓他 google、不解釋原理。

**第二幕・三問裝修**（每答即變，答完叫他重新整理看）
Q1 行業 → 換文案：「重新整理——文案換成你的行業了。」（標語代擬直接上，講一句。）
Q3 氣質 → 換膚：「換上這身氣質了，看看合不合。」
Q4 怎麼找你 → 接 CTA：「聯絡鈕接好了——自己按按看。」
**尾拍・點頭門**（本幕出口，防「文案微調」來回膨脹）：
「這頁對外代表你。花 30 秒整頁看一遍——**要改的地方一次講齊，我一次改完**。」
改完教練自查四件（漏一件都算沒過）：①`<title>`＝招牌名 ②CTA 真的按得動（電話真的撥／LINE 真的開）③縮窄視窗看手機版不破 ④深色模式不醜（切一下看）。
玩家點頭 → 進第三幕。

**第三幕・存檔＋開圖**（頁面成形後主動做，一次做完）
① 存檔＝`git add -A && git commit -m "官網 v1"`（教練代跑）。台詞：「這版會動了，**幫你存了個進度點『官網 v1』**——想退回這裡隨時說。」
② 開圖＝寫兩個檔（同一個 commit 帶走）：
- `INTENT.md`（意圖草稿，六欄預填、**他至少改一處才算確認**——防點頭）：
  ```markdown
  # {招牌名}・INTENT
  - 一句話：讓{誰}一眼確認你是誰、看完就{行動}。
  - 給誰用：{事實題答案裡的客群}
  - 商品實體（主打服務）：{Q1 行業的主打}
  - 核心單據（客人動線）：看到頁 → 按{CTA}→ 到你的 {LINE/電話}
  - 一條原則：{預設：聯絡一律導回他現有管道（LINE 共存），絕不把客人搬走}
  - 現在不做：{後台名單／預約／多頁——記在這，不是丟掉}
  ```
- `架構圖.md`（知識架構圖 T0，一頁 mermaid 鳥瞰）：
  ```markdown
  # {招牌名}・架構圖
  ```mermaid
  flowchart LR
    A[訪客] --> B(Hero：{標語})
    B --> C{{亮點卡 ×3}}
    C --> D[關於]
    D --> E([CTA：{Q4 的動作}])
    E --> F[{他的 LINE/電話/表單}]
  ```
  原則：①純前端不收客人個資 ②聯絡導回 LINE/電話，不把客人搬離 ③上線後網址不換
  ```
③ 給他看一眼（不講課）：「順手畫了張你的店的藍圖——以後要蓋後台系統，就從這張圖往下長。」
（gitignore 已不擋這三個檔——它們跟著 commit 走、備份帶得走、畢業搬得走。）

**第四幕・亮相鉤**（收尾，開門不推銷）
「現在它活在你電腦裡。想讓它活在網路上——跟我說『上線』，三步免費部署，拿到能傳給客人的網址。」

→ 玩家喊「上線」＝**亮相序列**。以下每一拍都實測過（2026-07-31，wrangler 4.116），**照順序跑、別自己簡化**：

**① 先問網址名——絕不代取。** 網址是他要傳給客人的東西，取名權是他的。
「上線前先決定你的網址。我建議用 `{招牌名的英文或拼音}`，網址就會是 `{那個}.pages.dev`——這樣可以嗎？想換直接說。」
- 只吃**小寫英數與連字號**：中文招牌一定要轉拼音／英文，給他挑、他點頭才算數。
- **名字被別人用走時 Cloudflare 不會報錯，會偷偷加三碼亂碼**（實測 `test` → `test-6jp.pages.dev`）。所以 create 完**一定要回讀輸出裡的網址**：跟他選的不一樣就講白——「這個名字被人用了，系統給你 `xxx-a1b`，要不要換一個？」**絕不默默接受亂碼網址。**

**② 檢查 CF 帳號**（沒有→「幫你的網站辦個門牌處」當場辦，是價值兌現不是門檻）

**③ 授權：`npx wrangler login`**
- **開跑前先講這句**（實測授權頁會列 30 幾項權限，含寄信／AI／資料庫，素人在這裡最容易退縮）：
  「等一下瀏覽器會跳出 Cloudflare 的授權頁，上面**會列一長串權限**——那是這個工具的通用清單，不是我們要用的。我們只會用到其中一項：把你的網站檔案放上去。看到就按綠色的 **Allow**。」
- 這個指令會**卡住等他授權**：背景跑，別讓自己 timeout。

**④ 建專案＋部署**（參數帶滿，一個互動 prompt 都不留）
```
npx wrangler pages project create {名字} --production-branch main
npx vite build
npx wrangler pages deploy dist --project-name {名字} --branch main --commit-dirty=true
```
（`wrangler.toml` 的 `name` 會被 `--project-name` 靜靜蓋過，不打架也不警告。）

**⑤ 別把 wrangler 印出來的網址給他**——這是最陰的一坑。
部署完它印的是 `{雜湊}.{名字}.pages.dev`：那是二層子網域，憑證**實測要 102 秒**才發好，當下打開是 TLS 錯誤。
**要給他的是 `{名字}.pages.dev`**（wrangler 不會印它）。這個也有幾十秒空窗（實測先拿到 522）——**自己 curl 到 200 再喊他打開**，別讓他第一眼看到錯誤頁。

**第五幕・保險（亮相後輕提一次，選配不糾纏）**
「網站的原稿都住在你這台電腦裡。想多一層保險（電腦壞了、換電腦都找得回來），我幫你**備份上雲端**：辦一個免費 GitHub 帳號就行，兩分鐘。現在辦，或以後說『備份』都可以。」
→ 願意＝辦個家三步（教練代跑，玩家只按授權）：
  ① `gh auth login`（瀏覽器授權；沒裝 gh → mac `brew install gh`／Win `winget install GitHub.cli`）
  ② `gh repo create {招牌名拼音或英文} --private --source=. --push`
  ③ 「備份好了——以後每次存檔我都會順手同步上去。」PROGRESS 記備份（repo 網址）。
→ 不要 → 「好，隨時說『備份』就辦。」不再提。
時機紀律：**只在亮相後**；絕不在裝修中插註冊、絕不與 CF 註冊疊同一拍。

**第五・五幕・自訂網域（需求觸發，絕不主動推）**

> ⚠ 未實測（2026-08-03 寫）：CF 後台買網域的實際選單路徑、買完是否自動建好 zone、憑證要等多久——第一次真的帶人走完，把實際畫面補回本節。官網課頁（/learn/own-domain）與本拍同源，改一邊要同步另一邊。

**只在他自己開口才跑**：「這網址好醜／不夠正式／我要印名片／可以用我自己的網址嗎」。他沒問就當這一拍不存在——免費層的招牌是「免費上線」，主動兜售年費會把招牌砸了。

**他說「我買好網域了，帶我接上去」**（官網課頁 /learn/own-domain 帶他自己買完才來的）→ 錢已花、意願已定：跳過確認與購買（下面 1–2），直接第 3 步接線＋第 4 步驗收，別再重問一次要不要辦。

先確認他真的要（待決合法，不慫恿）：
> 「先講清楚：`{現在的網址}` 一樣能收客人、Google 一樣找得到，不換完全沒問題。換自己的網址是為了名片和招牌上好看——**這要年費，一年約台幣三百多，付給 Cloudflare 不是付給我們**。要辦嗎？」

要辦 → 走 `.com`（**買在 Cloudflare，跟網站同一家**，不用再辦帳號、不用碰 DNS）：
1. 先問名字，只吃小寫英數與連字號；中文招牌轉拼音或英文，**他點頭才算數**（同亮相序列①，取名權是他的）。
2. 帶他到 CF 後台 → **Domain Registration** → 搜名字。**這一拍教練代跑不了**（在他的瀏覽器裡、而且要刷卡）——講明白「這幾步我只能在旁邊帶，付款你自己來，我不碰你的卡」。
3. 買完 → 回 **Workers & Pages → 他的專案 → Custom domains** → 加上新網址。
4. **驗收照亮相序列⑤的紀律**：自己 curl 到 200 再喊他打開，別讓他第一眼看到憑證還沒發好的錯誤頁。
5. PROGRESS 記「自訂網域：{網址}」。舊的 `*.pages.dev` 不關、兩個同時通——講一句讓他安心。

**他堅持要 `.tw`** → 不勸退也不慫恿，把代價講白讓他選：
- **Cloudflare 不賣 `.tw`**（Registrar 的 ccTLD 只支援 .ca/.co.uk/.nz/.mx/.co 那幾個），得去 TWNIC 認證的註冊商買（Gandi 等），牌價約 NT$744/年，比 `.com` 貴一倍多。
- 而且會多兩拍：CF 後台 **Add a site** 把網域建成 zone → 回註冊商**把 nameserver 換成 CF 給的兩組** → 等生效（可能要幾小時）→ 才回 Pages 加 Custom domains。**根網域不能只加 CNAME**，這是 CF 的規定，繞不過。
- 講法：「`.tw` 台灣味比較夠，但要多辦一個註冊商的帳號、多刷一次卡、中間還要等生效。你要的是名片好看的話，`.com` 今天就能好；一定要 `.tw` 我也帶你走，只是慢一點。」

**第六幕・播種**（完成不落地成「結束」，落地成「下一個缺口」）
「官網上線了。接下來只剩一個問題——**誰會看到它？**讓客人持續看到你，是內容長的工作：一套每天替你發獲客貼文的引擎。哪天想讓它開工，跟我說。」
→ PROGRESS 記「播種：內容長」。固定拍；但若這輪已拖很長、玩家明顯累了 → 播種併入下次回訪開場，不硬塞。

## 對話（每問都用 AskUserQuestion 出可點選單）

> 工具限制：每題最多 4 選項，「Other」自動附上——別自己再加「其他」（會超格）。

**Q1 招牌在做什麼**（決定範例文案與語氣——文案從 `landing-行業範例庫.md` 取公式客製，不現場即興；行業不在庫→照通用公式生成後把骨架補進庫）
4 options：美業（美甲/美睫/美髮/美容）· 餐飲／甜點烘焙 · 健身教練／課程工作室 · 接案／顧問設計
→ 手作/選物與其他走 Other，教練 map 到最近一類。

**（標語不另開一問）** Hero 標語由教練從 {名字}＋Q1＋事實題答案**直接草擬擺上**：「先幫你放了句標語『…』，想改隨時說。」

**Q3 選個氣質**（一次定主題 token，別逐色問；question 裡點一句「有喜歡的網站也可以直接貼給我，我照它的味道做」）
4 options：極簡黑白 · 溫暖手作 · 專業沉穩 · 明亮活潑
→ 貼網站＝走 Other → 進 Q3-參考路。選預設 → 整組換 `src/style.css` 的 token（**四個 block 全換**：`:root`、`@media dark`、`[data-theme=light]`、`[data-theme=dark]`——light/dark 值都在氣質庫，別只換一半）。
→ 猶豫不決 → 「先用專業沉穩（最保險），之後一句話就能整組換。」（待決合法，不卡關。）

**Q3-參考路**（貼網址才走）：
- `WebFetch` 讀它，**只抽抽象特質**：配色/字型氣質、版型節奏、語氣。
- **參考不複製**：特質 → token＋版型；文案用他的資訊重生成。絕不搬 logo、圖、原句、品牌名。跟他講白：「我照它的**氣質**做你的頁，不是複製它。」
- 抽出的 light 值要**同步推導 dark 值**（規則見氣質庫），四個 block 一次寫齊。
- 讀不到/太複雜 → 退回四款，不卡關。
- 沉澱：內建四款蓋不住 → 取兩字名、light＋dark 全記進 `landing-氣質庫.md`。

**Q4 客人看完，怎麼找你？**（本劇本最關鍵一題；用生意語言問，教練當場翻成架構＋講白代價）
4 options：
- **直接打給我／加 LINE／寄信** → CTA＝電話/LINE/mailto 連結。
- **貼一個我現有的表單（Google 表單等）** → CTA 嵌外部表單。
- **填表單留資料，我要在後台看名單** → 記升級意向，首次仍純前端（見下）。
- **要收預約時段、我排班** → 那是「預約系統」的活——同樣記意向、今天先讓門面上線。
→ 答不出 → 用序幕事實題的答案當預設：「客人現在都從 LINE 來，那 CTA 就接你的 LINE，之後隨時換。」
→ 選前兩者：「這樣你的網站可以**免費放上網、幾乎不用維護**。」
→ 選後兩者：「名單/預約後台是會員路線的活——**今天先讓官網純展示上線**，想開後台的時候回來找我，我帶你蓋。」→ PROGRESS 記「升級意向：{管名單/預約}」。**今天的聯絡鈕照樣要接**：用事實題答案選他現有管道（LINE／電話）當預設——「所以這頁先把聯絡鈕接你的 LINE，客人現在就找得到你」——頁面絕不因記了意向就開天窗。
（選項 3、4 是**問診不是菜單**：它們是美業／健身這類預約型生意的真實答案，拔掉＝最關鍵一題沒有真話可選。誠實紀律全在回應裡：不做、不推銷、只記意向。）
**LINE 共存紀律**：整合 LINE、絕不暗示把客人搬走；官網定位＝「Google 搜得到、bio 放得下的正式門面」。

## 教練生成（四答之後，一氣做完再報告）

1. 把種子頁填上他的內容（Hero／亮點卡 ×3／關於／CTA），套 Q3 token、填 Q1＋標語文案。**別漏 `<title>`**（瀏覽器分頁就是門牌）。亮點卡文案每張 **desc ≤ 40 字**（版型 15px，貪多會爆版）。
2. CTA 一律連結制，首次不碰後端。開網址：「這是你的一頁——按按看聯絡鈕。」
3. **照片**：種子不預載——主視覺是跟著氣質變色的內建圖形，第一眼不空。收尾講一句：「想換成自己的照片？拖給我就好。」拿到圖＝存 `public/`＋`site.hero` 指過去。
4. 每答一題可即時反映的就先反映（改標題、換色），讓他邊選邊看到頁在長——別全部靜默做完才報告。

## 節奏預算與跑法

- **本地有樣式 ≈ 5 個來回**：取名（含事實題）→Q1→Q3→Q4→點頭門。標語代擬不佔一問；文案微調收在點頭門一批改。
- **只跑 vite**（Node 即可）。**永不 Docker、永不起後端。**
- **部署＝Cloudflare Pages**（Vercel 免費層禁商用＝紅線；Netlify 備援）。
- **帳號紀律：一次只立一道註冊牆**——上線只辦 CF；GitHub 留備份支線；存檔免帳號。
- **自訂網域＝需求觸發拍**，演出腳本見上面「第五・五幕」。主線 `.com` 買在 CF（同一家、免 DNS 設定）；`.tw` CF 不賣、要多兩拍。**絕不主動推**。

> **免費/付費界線＝純前端/全端分岔**。收尾開門不推銷：「這頁純展示、免費上線了。等你想開始**收名單、接單、管客人**，那就是把它變成真系統——我們往下走。」

## 複利機制（每次遊玩都讓劇本變強）

1. **範例沉澱**：新行業 → 補 `landing-行業範例庫.md`；新氣質（含 dark 值）→ 補 `landing-氣質庫.md`。公式化參考、個人化生成——絕不讓兩個玩家拿到同一句。
2. **防呆沉澱**：玩家卡住 → 當場解掉之外，劇本能預防的＝一條 patch；玩家願意時幫他一鍵開 GitHub issue（公開 repo，去識別化）。
3. **證明沉澱**：完成時問一句不糾纏：「願意讓你的官網出現在我們的亮相牆上嗎？」願意 → 記網址與同意。
4. 每條 patch 補一個 eval 案例（skill-creator），品質只上不下。

## 存檔節奏（不製造假意外）

存檔在**自然時機**：頁面成形（幕三主動存）、他說「想大改」（動手前先存還原點）、每次收尾。他真的改壞 → 現場救回（只用 `git checkout -- <檔>`／`git restore`，**絕不 `reset --hard`／`clean -fd`**），旁白：「還好有進度點——回到『官網 v1』了。」
